## Requirement

When the user hovers the mouse over the "Home" tab in the top navigation bar
(header), the cursor must change to a pointer, signalling the tab is clickable.

## Live-app findings (verified)

Inspecting `https://tomato-food-delivery-zeta.vercel.app/`:

- The top navigation bar is `div.navbar`.
- The "Home" tab is an anchor (`<a>`), accessible name "Home", `href="/"`.
- `window.getComputedStyle(homeLink).cursor` returns `"pointer"`.
