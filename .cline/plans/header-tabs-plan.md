# Header Navigation Tabs — Test Plan

Generated by: planner-agent
Date: 2026-09-25
Live-app inspection: verified against https://tomato-food-delivery-zeta.vercel.app/

## Requirement

On the application home page, the header must render these tabs/controls:
Tomato logo, Home, Menu, Mobile App, Contact Us, Search, Cart, Sign In.

## Live-app findings (verified)

Top navigation bar (header) contains:

| Tab / control              | Role                     | Destination          | Signed-out?              |
| -------------------------- | ------------------------ | -------------------- | ------------------------ |
| Tomato logo                | link + img "Tomato logo" | `/`                  | yes                      |
| Home                       | link "Home"              | `/`                  | yes                      |
| Menu                       | link "Menu"              | `#explore-menu`      | yes                      |
| Mobile App                 | link "Mobile App"        | `#app-download`      | yes                      |
| Contact Us                 | link "Contact Us"        | `#footer`            | yes                      |
| Search                     | img "Search"             | n/a (search control) | yes                      |
| Cart                       | link + img "Cart"        | `/cart`              | yes                      |
| Sign In                    | button "Sign In"         | opens Login modal    | **only when signed out** |
| Profile (replaces Sign In) | img "Profile"            | profile menu         | when signed in           |

Important: when the user is signed in, the header shows a "Profile" avatar
instead of the "Sign In" button. The requirement's "Sign In" tab is therefore
only present in the signed-out state. Tests must assert Sign In from a fresh
(signed-out) session, and may assert Profile in a signed-in session.
